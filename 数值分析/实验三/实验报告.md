# 实验三：单细胞基因表达最小二乘拟合及细胞分化轨迹解析

## 一、实验目的

1. 掌握单细胞表达矩阵的预处理方法（高可变基因筛选、标准化），理解基因维度优化的核心思路。
2. 熟练运用最小二乘多项式拟合方法，结合细胞标签时序，实现基因表达曲线的拟合，掌握拟合优度与误差分析的计算方法，明确正则化对拟合效果的影响。
3. 学会基于细胞标签进行时间点分配，明确同一阶段内细胞的排序逻辑，避免时间点分配不合理导致的拟合失真。
4. 了解基于基因拟合趋势的细胞分化轨迹排序方法，初步理解细胞单分支/双分支分化机制。
5. 掌握实验数据的验证方法，能通过假设检验、相关性分析等手段验证实验结果的合理性。

## 二、实验原理

### 2.1 高可变基因筛选

单细胞RNA-seq表达矩阵通常包含数万个基因，其中大量为低表达或无差异表达的"噪声基因"。高可变基因（HVG）筛选通过计算变异系数（CV）保留表达变异最大的前20%-30%基因：

$$CV_i = \frac{\sigma_i}{\mu_i + \varepsilon}$$

其中 $\sigma_i$ 为标准差，$\mu_i$ 为均值，$\varepsilon=10^{-8}$ 防止除零错误。

### 2.2 表达矩阵标准化

采用Seurat标准方法消除细胞测序深度差异：

$$X_{ij}^{norm} = \ln\left(1 + \frac{X_{ij}}{\sum_k X_{kj}} \times 10000\right)$$

### 2.3 K-means基因聚类

将表达模式相似的基因归入同一模块，以模块中心向量替代单个基因进行拟合。K-means目标函数为最小化模块内平方和误差：

$$SSE = \sum_{c=1}^{k} \sum_{x_{gi} \in C_c} \| x_{gi} - \mu_c \|^2$$

最优模块数通过轮廓系数确定：

$$s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}}$$

### 2.4 时间点分配策略

采用"全局时间轴+阶段内局部排序"策略：
- 全局时间轴：每个阶段对应连续时间区间，阶段间间隔 $\Delta t = 1$
- 阶段内排序：选择相邻阶段间表达差异最大的模块作为驱动模块，按模块表达值排序细胞
- 时间点插值：在阶段内均匀插值分配时间点

### 2.5 最小二乘多项式拟合

设基因表达量 $y$ 与时间 $t$ 的拟合多项式为：

$$\hat{y}(t) = a_0 + a_1 t + a_2 t^2 + \dots + a_p t^p$$

通过最小化残差平方和（RSS）求解参数：

$$RSS = \sum_{j=1}^{n_s} (y_j - \hat{y}_j)^2$$

### 2.6 Lasso正则化

在RSS基础上增加 $L_1$ 正则化项：

$$\min_{a} \sum_{j=1}^{n_s} \left( y_j - \sum_{m=0}^{p} a_m t_j^m \right)^2 + \lambda \sum_{m=1}^{p} |a_m|$$

### 2.7 拟合优度评价

- 拟合优度 $R^2$：$R^2 = 1 - \frac{\sum(y_j - \hat{y}_j)^2}{\sum(y_j - \bar{y})^2}$
- 均方根误差 RMSE：$RMSE = \sqrt{\frac{1}{n_s}\sum(y_j - \hat{y}_j)^2}$

## 三、实验内容与步骤

### 3.1 实验环境

- Python 3.13
- numpy, pandas, scikit-learn, scipy, matplotlib
- 数据集：simulation（模拟双分支分化数据）

### 3.2 实验步骤

#### 步骤1：数据加载与预处理

1. 加载表达矩阵和细胞标签
2. 高可变基因筛选：计算每个基因的变异系数，保留CV最大的基因
3. 标准化处理：采用对数归一化消除测序深度差异

#### 步骤2：基因维度优化

1. 对HVG进行K-means聚类
2. 通过轮廓系数评估最优模块数（k=8~15）
3. 构建模块表达矩阵

#### 步骤3：时间点分配

1. 构建全局时间轴（Start→Left_Mid→Left_End / Start→Right_Mid→Right_End）
2. 对每个阶段筛选排序驱动模块（阶段间表达差异最大）
3. 阶段内细胞排序与均匀抽样
4. 时间点均匀插值分配

#### 步骤4：最小二乘曲线拟合

1. 对每个模块分别进行1、2、3次多项式拟合
2. OLS与Lasso正则化对比
3. 5折交叉验证选择最优正则化参数 $\lambda$

#### 步骤5：误差分析与假设检验

1. 计算各模块的 $R^2$ 和 RMSE
2. Pearson相关性检验验证基因表达与时间的关联
3. 残差方差分析

#### 步骤6：负对照实验

随机打乱时间点100次，验证原始拟合优度是否显著高于随机情况。

#### 步骤7：细胞轨迹排序

基于显著趋势基因投票进行细胞排序，通过NMI和ARI验证排序合理性。

## 五、讨论

### 5.1 关于拟合效果

实验结果显示，部分模块（如模块0、模块5）具有显著的时间趋势，而其他模块的拟合效果较差。这符合生物学实际：并非所有基因模块都参与分化过程，只有特定的驱动基因会呈现明显的时间依赖性表达变化。

### 5.2 关于正则化效果

由于数据质量较好（模拟数据），最优λ值较小（0.001），Lasso正则化对拟合结果的改善有限。在实际应用中，当数据噪声较大或样本量不足时，正则化的作用会更加显著。

### 5.3 关于时间点分配策略

本实验采用的时间点分配策略完全基于已知的细胞阶段标签和基因表达数据，不依赖伪时间算法，避免了循环论证问题。排序单调性检验和负对照实验均验证了该策略的有效性。

### 5.4 改进建议

1. 增加抽样细胞数量，降低残差方差
2. 尝试更高阶多项式或非线性拟合方法（如随机森林、SVR）
3. 对显著趋势模块进行功能富集分析，赋予生物学意义

## 六、结论

1. 成功实现了单细胞表达矩阵的预处理流程，包括高可变基因筛选、标准化和基因聚类降维。
2. 建立了基于细胞标签的时间点分配策略，排序单调性检验全部通过，负对照实验验证了轨迹的可信性。
3. 完成了最小二乘多项式拟合，识别出模块0和模块5具有显著的时间表达趋势。
4. 通过5折交叉验证确定了最优正则化参数λ=0.001。
5. 基于基因投票的轨迹排序方法成功恢复了细胞的阶段归属（NMI=1.0, ARI=1.0）。

本实验将数值分析方法（最小二乘拟合、正则化、假设检验）成功应用于单细胞生物信息学问题，实现了数学方法与生物学问题的有机结合。
