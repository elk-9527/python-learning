# 实验五：回归分析

## 练习 11.3

某建材实验室在做陶粒混凝土强度试验中，考察每立方米混凝土的水泥用量 x（kg）对 28 天后的混凝土抗压强度 y（kg/cm²）的影响，测得如下数据：

### 实验数据

| 水泥用量 x (kg/m³)  | 150  | 160  | 170  | 180  | 190  | 200  | 210  | 220  | 230  | 240  | 250  | 260  |
| :------------------ | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 抗压强度 y (kg/cm²) | 56.9 | 58.3 | 61.6 | 64.6 | 68.1 | 71.3 | 74.1 | 77.4 | 80.2 | 82.6 | 86.4 | 89.7 |

### 实验要求

1. **求 y 对 x 的线性回归方程；**
2. **试用 F 检验法检验线性回归效果的显著性（α = 0.05）；**

### 详细数学过程

#### 一、线性回归方程推导

**1. 回归模型**

假设线性回归模型为：
```
y = a + bx + ε
```
其中：
- y 是因变量（抗压强度）
- x 是自变量（水泥用量）
- a 是截距
- b 是回归系数
- ε 是随机误差

**2. 最小二乘法原理**

我们需要找到 a 和 b，使得残差平方和最小：
```
Q = Σ(y_i - ŷ_i)^2 = Σ(y_i - a - bx_i)^2
```

**3. 求偏导数并令其为零**

对 a 求偏导：
```
∂Q/∂a = -2Σ(y_i - a - bx_i) = 0
```

对 b 求偏导：
```
∂Q/∂b = -2Σ(y_i - a - bx_i)x_i = 0
```

**4. 正规方程组**

整理得正规方程组：
```
Σy_i = na + bΣx_i
Σx_i y_i = aΣx_i + bΣx_i^2
```

**5. 求解回归系数**

由第一个方程得：
```
a = ȳ - b x̄
```

代入第二个方程，解得：
```
b = (nΣx_i y_i - Σx_i Σy_i) / (nΣx_i^2 - (Σx_i)^2)
```

**6. 计算过程**

| 序号  |   x   |   y   |   x²   |   xy   |
| :---: | :---: | :---: | :----: | :----: |
|   1   |  150  | 56.9  | 22500  |  8535  |

|   9   |  230  | 80.2  | 52900  | 18446  |

计算得：
```
n = 12
Σx = 2460, Σy = 871.2
Σx² = 518600, Σxy = 182943

x̄ = 2460 / 12 = 205
ȳ = 871.2 / 12 = 72.6

b = (12×182943 - 2460×871.2) / (12×518600 - 2460²)
  = (2195316 - 2143152) / (6223200 - 6051600)
  = 52164 / 171600
  = 0.3039

a = 72.6 - 0.3039×205
  = 72.6 - 62.30
  = 10.30
```

**7. 回归方程**

```
ŷ = 10.28 + 0.3039x
```

#### 二、F检验法

**1. 平方和分解**

总平方和 SST：
```
SST = Σ(y_i - ȳ)^2
```

回归平方和 SSR：
```
SSR = Σ(ŷ_i - ȳ)^2
```

残差平方和 SSE：
```
SSE = Σ(y_i - ŷ_i)^2 = SST - SSR
```

**2. F统计量**

```
F = (SSR / 1) / (SSE / (n-2))
```

**3. 计算过程**

```
SST = Σy² - (Σy)²/n = 63476.84 - 871.2²/12 = 1324.53

SSR = b(Σxy - ΣxΣy/n) = 0.3039×(182943 - 2460×871.2/12) = 1321.42

SSE = SST - SSR = 1324.53 - 1321.42 = 3.11

F = (1321.42 / 1) / (3.11 / 10) = 4248.94
```

**4. 显著性检验**

自由度：df1 = 1, df2 = n-2 = 10

查F分布表，α=0.05时：
```
F_0.05(1, 10) = 4.96
```

由于 F = 4248.94 > 4.96，拒绝原假设，回归效果显著。

### Python 完整解答代码

```python
import numpy as np
from scipy import stats

# 实验数据
x = np.array([150, 160, 170, 180, 190, 200, 210, 220, 230, 240, 250, 260])
y = np.array([56.9, 58.3, 61.6, 64.6, 68.1, 71.3, 74.1, 77.4, 80.2, 82.6, 86.4, 89.7])
n = len(x)

# 计算基础统计量
sum_x = np.sum(x)
sum_y = np.sum(y)
sum_xy = np.sum(x * y)
sum_x2 = np.sum(x ** 2)
sum_y2 = np.sum(y ** 2)

# 计算回归系数 b 和截距 a
b = (n * sum_xy - sum_x * sum_y) / (n * sum_x2 - sum_x ** 2)
a = (sum_y - b * sum_x) / n

print(f"线性回归方程：y = {a:.4f} + {b:.4f}x")

# F 检验
y_mean = np.mean(y)
y_hat = a + b * x

# 回归平方和
SSR = np.sum((y_hat - y_mean) ** 2)
# 残差平方和
SSE = np.sum((y - y_hat) ** 2)
# 总平方和
SST = np.sum((y - y_mean) ** 2)

# F 统计量
F = (SSR / 1) / (SSE / (n - 2))

# 临界值
alpha = 0.05
F_critical = stats.f.ppf(1 - alpha, 1, n - 2)

print(f"\nF 检验结果：")
print(f"SSR = {SSR:.4f}")
print(f"SSE = {SSE:.4f}")
print(f"SST = {SST:.4f}")
print(f"F = {F:.4f}")
print(f"F 临界值（α=0.05）= {F_critical:.4f}")
print(f"显著性检验：{'回归效果显著' if F > F_critical else '回归效果不显著'}")
```

### 运行结果

```

F 检验结果：

F = 4152.5214

```

### 实验结论

1. **线性回归方程**：ŷ = 10.2829 + 0.3039x
2. **F 检验**：F 值（4152.52）远大于临界值（4.96），因此在 α = 0.05 的显著性水平下，线性回归效果显著。
